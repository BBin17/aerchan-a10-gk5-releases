# AerChan A10 GK5 固件

[查看最新版本并下载加密固件](https://bbin17.github.io/aerchan-a10-gk5-releases/)。

用 Safari 或 Chrome 下载 `.a10fw` 到手机，随后连接转速灯的 `AerChan-RPM` Wi‑Fi。打开 [设备设置页](http://192.168.11.1/)，展开「固件更新」，选择刚下载的文件，输入热点密码并上传。保持熄火和设备供电。重启后连上 AerChan-RPM，再打开新地址核对版本。

从 v1.0.15 更新时，先连原热点 `ZyRacing-RPM` 并通过 [旧设置页](http://192.168.4.1/) 上传。

升级包适用于已完成加密首刷的 A10 GK5。设备会解密升级包并校验固件签名，通过后才切换到新版本。历史固件见 [Releases](https://github.com/BBin17/aerchan-a10-gk5-releases/releases)。
